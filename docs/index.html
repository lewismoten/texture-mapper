Register the Windows version

The 2010 program opens its About box every five minutes and closes if you don't register. It's free now, so make your own serial number here. Type your name exactly as you'll type it in the program: capitals and spaces must match. In 2010 this was your Second Life avatar name.

In the program, click About, enter the same name and serial number, then click Register. The serial is worked out in your browser; nothing is sent anywhere.

Texture Mapper began as a Windows program I wrote in 2008 and released in 2010 for building in Second Life: use one uploaded texture on many faces, which saved upload fees and loaded faster. This web version does the same math in the browser. Still using the Windows version? Click to make a serial number. Source on GitHub (MIT).
