Texture Mapper

Drag a box around part of a texture to get the Second Life repeats and offset for it. Your image never leaves your browser.

Drag to select. Drag an edge or corner to resize, or the middle to move. Double-click to clear. Arrow keys nudge the box one pixel (Alt: ten); Shift+arrows resize it. You can also drop or paste an image here.

Still using the Windows version?

The 2010 program asks to be registered: every five minutes it opens its About box, and it closes if you don't register. It's free now, so you can make your own serial number here. Type your name exactly as you'll type it into the program's About box: it must match letter for letter, including capitals and spaces. In 2010 this was your Second Life avatar name, like Dedric Mauriac.

In the program, click About, enter the same name and this serial, then click Register. The serial is worked out in your browser and nothing is sent anywhere.

Texture Mapper began as a Windows program I wrote in 2008 and released in 2010 for building in Second Life: use one uploaded texture on many faces, which saved upload fees and loaded faster. This web version does the same math in the browser. Source on GitHub (MIT).
